# Lenguajes de Programación I
Apuntes, ejercicios y proyectos del curso **Lenguajes de Programación I** (EST303), enfocado
en fundamentos de programación y C++.

## Contenido
- **Unidad I:** algoritmos, DFD, sintaxis de C++, estructuras selectivas e iterativas, arreglos.
- **Unidad II:** funciones, ordenamiento (burbuja, shell, quicksort), recursividad, cadenas,
  archivos.
